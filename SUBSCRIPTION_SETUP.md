# 🔔 Настройка проверки подписки на канал

## 📝 Что нужно сделать

Для корректной работы проверки подписки на канал необходимо:

1. **Добавить бота в канал**
2. **Дать боту права администратора**
3. **Настроить параметры в `config.py`**

---

## 🚀 Пошаговая инструкция

### Шаг 1: Добавить бота в канал

1. Откройте ваш канал в Telegram (@fitclubmoscow)
2. Нажмите на название канала вверху
3. Выберите **"Администраторы"**
4. Нажмите **"Добавить администратора"**
5. Найдите вашего бота
6. Добавьте его

### Шаг 2: Настроить права бота

Боту нужны минимальные права:
- ✅ **НЕ нужны** права на публикацию сообщений
- ✅ **НЕ нужны** права на изменение информации
- ✅ Бот просто должен быть администратором для проверки подписчиков

### Шаг 3: Настроить `config.py`

Откройте файл `config.py` и убедитесь, что настроены правильные параметры:

```python
# Канал для голосования
VOTING_CHANNEL = "t.me/fitclubmoscow"
VOTING_CHANNEL_USERNAME = "@fitclubmoscow"  # Username канала с @
VOTING_CHANNEL_ID = None  # Можно оставить None, бот будет использовать username

# Проверка подписки на канал
CHECK_SUBSCRIPTION = True  # True - проверка включена, False - отключена
```

#### Вариант 1: Использовать username канала (проще)
```python
VOTING_CHANNEL_USERNAME = "@fitclubmoscow"
VOTING_CHANNEL_ID = None
```

#### Вариант 2: Использовать ID канала (надёжнее)
Чтобы узнать ID канала:

1. **Способ 1 - Через бота @username_to_id_bot:**
   - Отправьте ссылку на канал боту
   - Он вернёт ID

2. **Способ 2 - Через API:**
   - Перешлите любое сообщение из канала боту @getidsbot
   - Он покажет ID канала

3. **Способ 3 - Через веб-интерфейс:**
   - Откройте канал в Telegram Web (web.telegram.org)
   - ID будет в URL: `web.telegram.org/#/im?p=c1234567890`
   - ID канала: `-1001234567890` (добавьте `-100` к числу из URL)

После получения ID:
```python
VOTING_CHANNEL_ID = -1001234567890  # Ваш реальный ID
```

### Шаг 4: Протестировать

1. Перезапустите бота:
```bash
sudo systemctl restart halloween-bot
```

2. Отпишитесь от канала (для теста)

3. Отправьте боту `/start`

4. Вы должны увидеть сообщение с предложением подписаться

5. Подпишитесь на канал

6. Нажмите "✅ Я подписался!"

7. Если всё работает - появится приветствие и кнопка "Участвовать"

## 🔧 Отключение проверки подписки

Если хотите отключить проверку подписки (например, для тестирования):

В `config.py` измените:
```python
CHECK_SUBSCRIPTION = False
```

И перезапустите бота:
```bash
sudo systemctl restart halloween-bot
```

## ❌ Возможные проблемы

### Проблема 1: Бот не может проверить подписку

**Симптомы:**
- Бот всегда говорит, что пользователь не подписан
- В логах ошибка: "Chat not found" или "Bot was kicked"

**Решение:**
1. Убедитесь, что бот добавлен в канал как администратор
2. Проверьте правильность username или ID канала
3. Убедитесь, что канал публичный или бот имеет доступ

### Проблема 2: Ошибка "Forbidden: bot was blocked by the user"

**Решение:**
- Это нормально - пользователь заблокировал бота
- Бот корректно обрабатывает эту ситуацию

### Проблема 3: Проверка всегда проходит успешно

**Симптомы:**
- Даже неподписанные пользователи проходят проверку

**Возможные причины:**
1. `CHECK_SUBSCRIPTION = False` в конфиге
2. Неправильный username/ID канала
3. Бот обрабатывает ошибки и пропускает пользователей при сбое проверки

**Решение:**
```bash
# Проверьте логи
sudo journalctl -u halloween-bot -n 50 | grep "Ошибка проверки подписки"

# Проверьте конфиг
cat ~/HalloweenBotPHG/config.py | grep CHECK_SUBSCRIPTION
cat ~/HalloweenBotPHG/config.py | grep VOTING_CHANNEL
```

## 📱 Как это работает для пользователя

1. Отправляет `/start`
2. Видит сообщение:
   ```
   🎃 Добро пожаловать на конкурс костюмов Хэллоуин!
   
   📢 Для участия в конкурсе необходимо подписаться на наш канал.
   
   После подписки нажмите кнопку «✅ Я подписался!»
   ```
3. Кнопки:
   - `📢 Подписаться на канал` (ссылка на канал)
   - `✅ Я подписался!` (проверка подписки)

### Сценарий 2: Пользователь подписан

1. Отправляет `/start`
2. Сразу видит приветствие и кнопку "Участвовать 🎃"

2. Видит всплывающее сообщение:
   ```
   ❌ Вы ещё не подписались на канал. 
   Пожалуйста, подпишитесь и попробуйте снова.
   ```
3. Кнопки остаются на месте

## 📞 Поддержка

Если проверка подписки не работает:

1. Проверьте логи: `sudo journalctl -u halloween-bot -n 100`
2. Убедитесь, что бот - администратор канала
3. Попробуйте использовать ID канала вместо username
4. Временно отключите проверку: `CHECK_SUBSCRIPTION = False`
