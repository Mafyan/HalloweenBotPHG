# 🎃 Telegram бот для конкурса фотографий в костюмах

Бот для сбора фотографий участников конкурса костюмов на Хэллоуин с системой модерации.

## 🚀 Возможности

- ✅ Сбор заявок с фотографиями
- 🏢 Выбор клуба (Лихоборы / Селигерская)
- 📱 Сбор контактных данных (телефон)
- ✅ Согласие на обработку персональных данных
- 🔒 Система модерации заявок
- ⏰ Автоматическое закрытие приёма по дедлайну (31.10.2025 23:00 МСК)
- 📊 Статистика заявок
- 📢 Публикация одобренных заявок по команде

## 📦 Установка

1. Установите Python 3.8 или выше

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка

Все настройки находятся в файле `config.py`:
- `BOT_TOKEN` - токен вашего бота
- `MODERATION_CHAT_ID` - ID чата для модерации
- `DEADLINE` - дедлайн приёма заявок
- `CLUBS` - настройки клубов
- `VOTING_CHANNEL` - канал для голосования

## 🎮 Запуск

```bash
python bot.py
```

## 📝 Использование

### Для участников:

1. `/start` - начать регистрацию
2. Выбрать клуб
3. Согласиться с обработкой данных
4. Отправить номер телефона
5. Отправить фото в костюме

### Для модераторов (в модераторском чате):

- Одобрить/отклонить заявки кнопками под сообщениями
- `/stats` - посмотреть статистику заявок
- `/finish` - завершить приём и опубликовать одобренные заявки

## 🗂️ Структура проекта

- `bot.py` - основной файл бота с обработчиками
- `config.py` - конфигурация
- `database.py` - работа с базой данных SQLite
- `requirements.txt` - зависимости Python
- `contest_bot.db` - база данных (создаётся автоматически)

## 💾 База данных

Бот использует SQLite для хранения:
- Заявок участников
- Статусов модерации
- Состояний бота

## 🔐 Безопасность

- Номера телефонов хранятся в локальной базе данных
- Требуется согласие на обработку персональных данных
- Отклонённые заявки автоматически удаляются после команды `/finish`

## 📊 Статусы заявок

- `SUBMITTED` - отправлено на модерацию
- `APPROVED` - одобрено модератором
- `REJECTED` - отклонено модератором

## ⏰ Дедлайн

Приём заявок автоматически закрывается 31 октября 2025 в 23:00 по московскому времени.
После этого пользователи увидят сообщение о завершении приёма и информацию о голосовании.

## 🆘 Поддержка

При возникновении проблем проверьте:
1. Правильность токена бота
2. Права бота в модераторском чате
3. Наличие установленных зависимостей
